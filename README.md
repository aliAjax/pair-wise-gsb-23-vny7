# hxwl-09 半导体洁净室巡检

洁净等级阈值版本管理、粒子计数判定、复核锁定与审计追踪看板。

## 技术栈

React + Vite + TypeScript + CSS，IndexedDB 本地持久化（无后端依赖）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 功能

- **阈值版本化判定**：新建巡检记录时按当前生效的阈值版本判定，测量值 ≥ 上限（含等于）即判异常，达到上限 90%（区间型指标为距边界 10% 量程）判关注
- **复核锁定**：厂务工程师复核通过后记录锁定，任何修改在存储层被拒绝
- **阈值版本管理**：厂务工程师可发布新阈值版本，仅影响之后新建的记录；历史记录始终按各自创建时的阈值版本显示判定
- **乐观锁并发控制**：每条记录带版本号，两个页面同时编辑同一记录时，晚提交方看到版本冲突提示，草稿保留且不覆盖对方已保存的结果，可基于最新版本继续编辑
- **本地持久化恢复**：未提交草稿（自动保存）、已提交记录、审计轨迹均存于 IndexedDB，页面关闭后重新打开自动恢复
- **导出摘要**：CSV 导出含记录版本、阈值版本与判定明细（带 BOM，Excel 可直接打开）
- **跨标签页同步**：通过 BroadcastChannel 通知其他页面刷新列表
- **角色权限**：巡检员（录入）、厂务工程师（复核 + 发布阈值）、班组长（只读 + 导出）

## 代码结构

- `src/types.ts` — 领域类型（记录、阈值版本、草稿、审计）
- `src/domain.ts` — 判定逻辑（等于上限判异常）与种子数据
- `src/db.ts` — IndexedDB 持久层；版本检查 + 写入 + 审计在同一事务完成，保证并发安全
- `src/App.tsx` — 界面（录入表单、判定预览、记录列表、阈值管理、审计轨迹、冲突处理）
